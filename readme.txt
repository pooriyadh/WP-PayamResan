ارسال خودکار و دستی انواع پست تایپ‌های وردپرس (سازگار با جت‌انجین و متاباکس‌ها) به کانال‌های پیام‌رسان بله و تلگرام.

== Description ==

افزونه **WP PayamResan** یک راهکار سبک، تمیز و رایگان برای اتصال سایت وردپرسی به پیام‌رسان‌های **بله (Bale)** و **تلگرام (Telegram)** است.

امکانات کلیدی:

* شناسایی پویا و خودکار تمام پست تایپ‌های قابل ارسال (نوشته، برگه، محصول ووکامرس، پست تایپ‌های JetEngine و...)
* فعال‌سازی مستقل برای بله، تلگرام یا هر دو هم‌زمان
* خواندن و نمایش متادیتاهای پیش‌فرض وردپرس و فیلدهای ساخته‌شده با **JetEngine**، **ACF**، **Meta Box**، **Pods** و متاباکس‌های سفارشی
* تنظیم ارسال به صورت اتوماتیک، دستی یا ترکیبی به ازای هر پست تایپ
* تست اتصال ربات و بررسی دسترسی ادمین کانال + ارسال پیام تستی برای هر دو پیام‌رسان
* الگوی پیام اختصاصی برای هر پست تایپ به همراه پیش‌نمایش زنده
* ثبت تاریخچه کامل ارسال‌ها و خطاها

Author: پوریا دایی حسینی (pouriadaeihosseini@gmail.com)

== Installation ==

1. پوشه افزونه را در مسیر `/wp-content/plugins/WP-PayamResan` قرار دهید یا فایل ZIP را از پیشخوان وردپرس بارگذاری کنید.
2. افزونه **WP PayamResan** را از منوی «افزونه‌ها» فعال کنید.
3. از منوی **WP PayamResan** وارد تنظیمات شوید و توکن و شناسه کانال بله و/یا تلگرام را وارد و تست کنید.
4. از تب «پست تایپ‌ها و متادیتا» پست تایپ‌های مورد نظر خود را فعال و الگوی پیام را تنظیم نمایید.
