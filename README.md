# WP PayamResan

[![Version](https://img.shields.io/badge/Version-1.0.0-blue.svg)](./CHANGELOG.md)
[![WordPress](https://img.shields.io/badge/WordPress-5.8%2B-21759b.svg)](https://wordpress.org/)
[![PHP](https://img.shields.io/badge/PHP-7.4%2B-777bb4.svg)](https://www.php.net/)
[![License](https://img.shields.io/badge/License-GPL--2.0--or--later-green.svg)](./LICENSE)

افزونه حرفه‌ای و رایگان وردپرس برای ارسال **خودکار و دستی** تمامی پست تایپ‌ها (نوشته‌ها، برگه‌ها، محصولات ووکامرس، پست تایپ‌های **JetEngine** و متاباکس‌های سفارشی) به کانال‌های پیام‌رسان **بله (Bale)** و **تلگرام (Telegram)**.

---

## ✨ امکانات کلیدی

- **شناسایی خودکار تمام پست تایپ‌های قابل ارسال**: شناسایی پویای پست تایپ‌های پیش‌فرض وردپرس، ووکامرس و هر پست تایپ سفارشی (CPT) ساخته‌شده با جت‌انجین، ACF یا کد سفارشی (به همراه گزینه نمایش CPTهای غیرعمومی دارای UI).
- **پشتیبانی هم‌زمان و مستقل از بله و تلگرام**:
  - امکان فعال‌سازی **فقط بله**، **فقط تلگرام** یا **هر دو پیام‌رسان به‌صورت هم‌زمان**.
  - پشتیبانی از چند کانال به صورت عمومی یا کانال اختصاصی به ازای هر پست تایپ.
  - پشتیبانی از آدرس پایه سفارشی (Proxy / Cloudflare Worker) برای تلگرام در سرورهای محدودشده.
  - آپلود مستقیم فایل تصویر از هاست (`multipart/form-data`) با Fallback هوشمند به متن در صورت خطای تصویر.
- **سازگاری کامل با JetEngine و سایر افزونه‌های متاباکس**:
  - شناسایی و خواندن متادیتاهای پیش‌فرض وردپرس (`wp_postmeta`) و فیلدهای **JetEngine** (فیلدهای CPT، متاباکس‌ها و Custom Meta Storage)، **ACF**، **Meta Box**، **Pods** و متادیتاهای ووکامرس/سئو.
  - پشتیبانی از انواع فیلدهای پیچیده جت‌انجین شامل `Repeater`، `Checkbox`، `Switcher`، `Select/Radio`، `Date/Time`، `Media`، `Gallery` و `Posts/Relations`.
  - زمان‌بندی هوشمند پس از ذخیره کامل متاباکس‌ها در ویرایشگر کلاسیک و گوتنبرگ (`meta-box-loader`).
- **ارسال اتوماتیک و دستی منعطف**:
  - تنظیم حالت هر پست تایپ: **اتوماتیک + دستی**، **فقط اتوماتیک** یا **فقط دستی**.
  - متاباکس اختصاصی در صفحه ویرایش مطلب برای ارسال فوری دستی، متن سفارشی یا جلوگیری از ارسال خودکار همان مطلب.
  - اکشن سریع در لیست نوشته‌ها، ارسال گروهی (Bulk Action) و صفحه اختصاصی «ارسال دستی» با پیش‌نمایش زنده.
- **تست اتصال و ارسال پیام آزمایشی**:
  - بررسی اعتبار توکن ربات (`getMe`)، یافتن کانال (`getChat`) و بررسی ادمین بودن ربات (`getChatMember`) به صورت مجزا برای بله و تلگرام.
  - دکمه ارسال پیام تستی زنده به کانال برای اطمینان از عملکرد صحیح پیش از انتشار مطالب.
- **گزارش ارسال (Logs)**: ثبت تمامی ارسال‌های خودکار، دستی، گروهی و تستی با وضعیت، شناسه پیام و جزئیات خطا.

## 📦 نصب و راه‌اندازی

1. این مخزن را دانلود کنید (یا با `git clone` در مسیر `wp-content/plugins/WP-PayamResan` قرار دهید):
   ```bash
   cd wp-content/plugins
   git clone https://github.com/pooriyadh/WP-PayamResan.git
   ```
2. در پیشخوان وردپرس وارد بخش **افزونه‌ها (Plugins)** شده و **WP PayamResan** را فعال کنید.
3. از منوی **WP PayamResan** در پیشخوان، تنظیمات تلگرام و/یا بله را پیکربندی کنید.

---

## 🤖 راهنمای تنظیم ربات‌ها

### ۱. پیام‌رسان بله (Bale)
1. در پیام‌رسان بله وارد گفتگو با بازوی پدر به آدرس `@botfather` (`ble.ir/botfather`) شوید و یک بازو بسازید.
2. توکن دریافتی را در تب **بله** افزونه وارد کنید.
3. بازو را به عنوان **مدیر (Administrator)** با مجوز ارسال پیام به کانال بله خود اضافه کنید.
4. نام کاربری کانال (مثلاً `@mychannel`) یا شناسه عددی چت را وارد کنید و گزینه **فعال‌سازی بله** را روشن نمایید.
5. از بخش **تست اتصال و پیام آزمایشی بله** اتصال و ارسال پیام تستی را بررسی کنید.

### ۲. تلگرام (Telegram)
1. در تلگرام با `@BotFather` ربات خود را بسازید و توکن را دریافت کنید.
2. ربات را به عنوان **Administrator** با دسترسی `Post Messages` به کانال اضافه کنید.
3. در تب **تلگرام** افزونه، توکن و شناسه کانال (مثل `@mychannel` یا `-1001234567890`) را وارد و تلگرام را فعال کنید.
4. *(اختیاری)* اگر هاست شما به `api.telegram.org` دسترسی مستقیم ندارد، آدرس پروکسی یا Cloudflare Worker خود را در فیلد **آدرس پایه API تلگرام** وارد کنید.
5. با دکمه‌های **بررسی اتصال** و **ارسال پیام تستی** از صحت اتصال مطمئن شوید.

## 🧩 متغیرهای الگو و متادیتاها (JetEngine / MetaBox)

در تب **پست تایپ‌ها و متادیتا** می‌توانید برای هر پست تایپ الگوی اختصاصی بسازید و از متغیرهای زیر استفاده کنید:

| متغیر | توضیح |
| --- | --- |
| `{post_title}` | عنوان نوشته / محصول / رکورد |
| `{post_excerpt}` | خلاصه نوشته (یا خلاصه خودکار متن) |
| `{post_content}` | متن کامل (محدودشده بر اساس تنظیمات) |
| `{post_url}` | لینک کامل مطلب |
| `{short_url}` | لینک کوتاه وردپرس |
| `{post_author}` | نام نویسنده |
| `{post_date}` | تاریخ انتشار |
| `{post_type}` | نام نمایشی پست تایپ |
| `{categories}` | دسته‌بندی‌ها به صورت هشتگ |
| `{tags}` | برچسب‌ها به صورت هشتگ |
| `{tax:taxonomy_slug}` | مقادیر هر تاکسونومی سفارشی |
| `{meta:field_key}` | مقدار متادیتای پیش‌فرض، JetEngine، ACF، Meta Box یا ووکامرس |
| `{site_name}` / `{site_url}` | نام و آدرس وب‌سایت |

### بلوک‌های شرطی
برای نمایش یک خط یا بخش **فقط در صورت پر بودن مقدار متغیر** می‌توانید از ساختار شرطی استفاده کنید:

```text
<b>{post_title}</b>

{if:meta:price}💰 قیمت: {meta:price} تومان
{/if}{if:meta:city}📍 شهر: {meta:city}
{/if}
🔗 <a href="{post_url}">مشاهده جزئیات</a>
```

افزونه به‌صورت خودکار این ساختار را برای **تلگرام (HTML)** و **بله (Markdown استاندارد بله)** تبدیل و بهینه‌سازی می‌کند.

## 🛠️ هوک‌ها و فیلترهای توسعه‌دهندگان (Hooks & Filters)

| نام هوک | نوع | توضیح |
| --- | --- | --- |
| `wp_payamresan_excluded_post_types` | Filter | تغییر لیست پست تایپ‌های نادیده‌گرفته‌شده |
| `wp_payamresan_available_post_types` | Filter | فیلتر کردن لیست نهایی پست تایپ‌های شناسایی‌شده |
| `wp_payamresan_discovered_meta_fields` | Filter | افزودن یا تغییر متادیتاهای شناسایی‌شده برای هر پست تایپ |
| `wp_payamresan_raw_meta_value` | Filter | تغییر مقدار خام متادیتا پیش از فرمت‌دهی |
| `wp_payamresan_switcher_labels` | Filter | سفارشی‌سازی برچسب بله/خیر برای فیلدهای Switcher |
| `wp_payamresan_resolve_placeholder` | Filter | افزودن متغیرهای سفارشی جدید در الگوها |
| `wp_payamresan_after_dispatch` | Action | اجرا بلافاصله پس از ارسال یک مطلب به پیام‌رسان‌ها |
| `wp_payamresan_upgraded` | Action | اجرا پس از ارتقای نسخه افزونه |
